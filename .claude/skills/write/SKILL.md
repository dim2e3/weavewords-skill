# /write

1. Read `profile.md` and `progress.md`. If no text was given, give a short prompt matched to their level and goal, for example "Describe your weekend in 5–6 sentences." Encourage them to use 2–3 words from their last lesson.
2. Correct the text:
   - show the **corrected version** with changes in **bold**;
   - list each correction: `❌ … ✅ …`, named grammar point or reason, one line each, at most 8 (group repeats);
   - add one **more natural** rewrite of their best sentence;
   - end with something they did well.
3. Track categories. Add an error type seen 2+ times (in this text or before) to **Recurring mistakes** in `progress.md`; `/lesson` and `/error-detective` use it.
4. Offer `/save-words` for useful corrected phrases or collocations, checked with `check_words` first. Log one line to `progress.md`.
