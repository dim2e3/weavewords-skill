# AI-репетитор Weavewords

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Polski](README.pl.md) · [Português](README.pt.md) · [По-русски](README.ru.md)

Персональний репетитор іноземної мови в Claude Code за 5 хвилин, без програмування.

Репетитор:
- веде за планом курсу під ваш рівень;
- проводить **ті самі уроки з 8 розділів, що й застосунок Weavewords** (відкриття правил, колокації, словотвір, пошук помилок, говоріння…);
- перевіряє кожну відповідь;
- пам’ятає ваші помилки;
- синхронізує все з акаунтом **Weavewords**: нові слова потрапляють у словник, повторення й уроки в чаті оновлюють розклад інтервальних повторень, а XP і серію днів видно в застосунку.

Працює для англійської, німецької, іспанської, французької, польської, російської та української.

## Швидкий старт

1. Встановіть [Claude Code](https://claude.com/claude-code).
2. Склонуйте репозиторій і запустіть Claude:
   ```bash
   git clone https://github.com/dim2e3/weavewords-skill.git
   cd weavewords-skill
   claude
   ```
   Підтвердіть підключення MCP-сервера `weavewords`.
3. Підключіть акаунт: `/mcp` → **weavewords** → **Authenticate**. Відкриється сторінка Weavewords: увійдіть (або зареєструйтеся) і натисніть **Дозволити**.
4. `/setup` → `/plan-lessons` → `/lesson`.

Уроки працюють і без підключення. Збереження слів, повторення в чаті та збереження уроків в акаунт потребують **Weavewords Pro**.

## Команди

| Команда | Що робить |
|---|---|
| `/setup` | Мова, рівень, мета; перевірка підключення |
| `/plan-lessons` | План курсу під ваш рівень |
| `/lesson [n\|тема] [хвилини]` | Повний урок з 8 розділів довкола слів до повторення |
| `/save-words` | Зберегти слова у словник Weavewords |
| `/review` | Сьогоднішні повторення прямо в чаті |
| `/quiz` | Тест із варіантами на слова до повторення |
| `/discover`, `/collocations`, `/word-forms`, `/error-detective` | Короткі вправи (по одному розділу уроку) |
| `/speak [тема]` | Говоріння з коучингом (текстом чи голосом) |
| `/story [тема]` | Текст для читання з ваших слів |
| `/write` | Письмо з виправленнями |
| `/mine-words` | Знайти слова для вивчення в будь-якому тексті |
| `/replay-lesson` | Повторити урок, збережений в акаунті |
| `/daily` | Щоденна рутина на 10–15 хвилин |
| `/progress` | Ваш прогрес і наступний крок |

Можна й звичайними словами: *«давай займатися»*, *«перевір мене»*, *«повтори урок 3»*.

## Інші AI-застосунки

MCP-сервер Weavewords: `https://api.weavewords.org/mcp` (вхід через OAuth).
- **Claude.ai:** Settings → Connectors → *Add custom connector*.
- **ChatGPT:** Settings → Apps & Connectors → Advanced → *Developer mode*.
- **Codex:** `codex mcp add weavewords --url https://api.weavewords.org/mcp` і `codex mcp login weavewords`.
- **Cursor / VS Code:** додайте HTTP MCP-сервер `weavewords` з цією адресою.

Там, де немає скілів, попросіть асистента прочитати `CLAUDE.md` і потрібний `.claude/skills/<назва>/SKILL.md`.

## Приватність

- `progress.md` і згенеровані уроки лишаються на вашому комп’ютері.
- Підключення отримує лише ті дозволи, які ви підтвердили. Відключити його можна в Weavewords → Налаштування → **AI apps**.
