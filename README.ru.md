# AI-репетитор Weavewords

[English](README.md) · [Українською](README.uk.md)

Личный репетитор иностранного языка в Claude Code за 5 минут, без программирования.

Репетитор:
- ведёт по плану курса под ваш уровень;
- проводит **те же уроки из 8 разделов, что и приложение Weavewords** (открытие правил, коллокации, словообразование, поиск ошибок, говорение…);
- проверяет каждый ответ;
- помнит ваши ошибки;
- синхронизирует всё с аккаунтом **Weavewords**: новые слова попадают в словарь, повторения в чате обновляют расписание интервальных повторений, а уроки и XP видны в приложении.

Работает для английского, немецкого, испанского, французского, польского, русского и украинского.

## Быстрый старт

1. Установите [Claude Code](https://claude.com/claude-code).
2. Склонируйте репозиторий и запустите Claude:
   ```bash
   git clone https://github.com/dim2e3/weavewords-skill.git
   cd weavewords-skill
   claude
   ```
   Подтвердите подключение MCP-сервера `weavewords`.
3. Подключите аккаунт: `/mcp` → **weavewords** → **Authenticate**. Откроется страница Weavewords: войдите (или зарегистрируйтесь) и нажмите **Разрешить**.
4. `/setup` → `/plan-lessons` → `/lesson`.

Уроки работают и без подключения. Сохранение слов, повторения в чате и сохранение уроков в приложение требуют **Weavewords Pro**.

## Команды

| Команда | Что делает |
|---|---|
| `/setup` | Язык, уровень, цель; проверка подключения |
| `/plan-lessons` | План курса под ваш уровень |
| `/lesson [n\|тема] [минуты]` | Полный урок из 8 разделов вокруг слов к повторению |
| `/save-words` | Сохранить слова в словарь Weavewords |
| `/review` | Сегодняшние повторения прямо в чате |
| `/quiz` | Тест с вариантами на слова к повторению |
| `/discover`, `/collocations`, `/word-forms`, `/error-detective` | Короткие упражнения (по одному разделу урока) |
| `/speak [тема]` | Говорение с разбором (текстом или голосом) |
| `/story [тема]` | Текст для чтения из ваших слов |
| `/write` | Письмо с исправлениями |
| `/mine-words` | Найти слова для изучения в любом тексте |
| `/replay-lesson` | Пройти здесь урок из приложения Weavewords |
| `/daily` | Ежедневная рутина на 10–15 минут |
| `/progress` | Ваш прогресс и следующий шаг |

Можно и обычными словами: *«давай заниматься»*, *«проверь меня»*, *«повтори урок 3»*.

## Другие AI-приложения

MCP-сервер Weavewords: `https://api.weavewords.org/mcp` (вход через OAuth).
- **Claude.ai:** Settings → Connectors → *Add custom connector*.
- **ChatGPT:** Settings → Apps & Connectors → Advanced → *Developer mode*.
- **Codex:** `codex mcp add weavewords --url https://api.weavewords.org/mcp` и `codex mcp login weavewords`.
- **Cursor / VS Code:** добавьте HTTP MCP-сервер `weavewords` с этим адресом.

Там, где нет скиллов, попросите ассистента прочитать `CLAUDE.md` и нужный `.claude/skills/<имя>/SKILL.md`.

## Приватность

- `progress.md` и сгенерированные уроки остаются на вашем компьютере.
- Подключение получает только те разрешения, которые вы подтвердили. Отключить его можно в Weavewords → Настройки → **AI apps**.
